Baba eMitra AI - Starter Website

1. Open index.html in Chrome to test the website.
2. This version includes a local FAQ/demo AI response engine; it does NOT call a paid API and needs no API key.
3. To connect a real Gemini/other AI model later, add a secure backend/server. Never put a private API key directly in browser JavaScript.
4. The site is mobile responsive and can later be wrapped into an Android APK using a webview/Kodular-style app.
